1. Поиск кратчайшего пути во взвешенном графе (алгоритм Дейкстры)

Пусть дан взвешенный граф без рёбер отрицательного веса. Алгоритм Дейкстры находит длины кратчайших путей от одной стартовой вершины S до всех остальных вершин графа.

Пошаговая схема алгоритма Дейкстры:
1. Присвоим стартовой вершине метку d[S] = 0, всем остальным вершинам — d[v] = ∞. Все вершины отметим как непосещённые.
2. Среди всех непосещённых вершин выберем вершину u с минимальной текущей меткой d[u].
3. Для каждого непосещённого соседа v выполним релаксацию ребра (u, v):
if d[u] + w(u, v) < d[v]: d[v] = d[u] + w(u, v)
4. Отметим вершину u как посещённую (её метка d[u] стала окончательной) и повторим шаги 2–4.

2. Количество путей в направленном ациклическом графе (DAG)

Для подсчёта числа различных маршрутов в ориентированном ациклическом графе используют метод динамического программирования: количество путей до вершины X равно сумме количества путей до всех вершин, из которых дуги входят в X.

Решение задач с двойным ограничением (формат ЕГЭ №13):
Если требуется найти количество путей из S в T, обязательно проходящих через вершину A и НЕ проходящих через вершину B:
1. Присвойте N(B) = 0 (вычеркните запрещённую вершину B и все связанные с ней дуги).
2. Удалите все дуги, которые позволяют обойти обязательную вершину A стороной (или разбейте задачу на произведение двух независимых этапов: N(S → A) × N(A → T) при условии N(B) = 0).
Практикум 2: Подсчитай количество путей из А в З (через В, избегая Е)

Найди количество различных путей из города А в город З, которые обязательно проходят через город В и НЕ проходят через город Е. На схеме пунктиром уже отмечены дуги, нарушающие эти условия:

Разбор по вершинам:
• N(Б) = N(А) = 1;  N(Г) = N(А) = 1.
• N(В) = N(А) + N(Б) + N(Г) = 1 + 1 + 1 = 3.
• Стрелка Б → Д отброшена (иначе путь обойдёт В), поэтому N(Д) = N(В) = 3.
• Вершина Е запрещена (N(Е) = 0), поэтому N(Ж) = N(В) + N(Д) = 3 + 3 = 6.
• N(З) = N(Д) + N(Ж) = 3 + 6 = 9.

3. Дешифровка весовой матрицы и представление графов в Python

При решении задач на сопоставление таблицы (весовой матрицы) и графа сначала выписывают степени всех вершин на схеме и количество заполненных ячеек в каждой строке таблицы, а затем анализируют степени соседних вершин.

Алгоритм дешифровки:
1. Единственная вершина степени 1 на схеме — А, в таблице это П4 (связана только с П3). Значит, П3 = Б.
2. Соседи Б (П3) имеют степени 1 (А = П4), 2 (В = П1) и 3 (Г = П2).
3. Из оставшихся двух вершин степень 3 у Д (П5), а степень 2 у Е (П6).
4. Сравните маршруты из А в Е: А–Б–В–Д–Е = 7 + 4 + 5 + 2 = 18 (короче, чем через Г).
